# VolvControl API

API do projeto VolvControl.

## Tecnologias

- .NET 7
- ASP.NET Core Web API
- JWT para autenticação
- Autorização por policy (position_description)

## Execução

Configure a connection string `DefaultConnection` e a chave `Jwt:Key` em appsettings e execute:

```bash
dotnet run --project volvcontrol-api
```

## Swagger

Em ambiente de desenvolvimento: `/swagger`
